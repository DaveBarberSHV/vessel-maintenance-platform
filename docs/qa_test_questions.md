# Fathom - Polaris Q&A Test Questions

*September 2026 — pre-rollout structured testing.*
*Goal: verify answers are correct and well-cited, not just plausible.*

## How to use this

Ask each question cold in the app — no hints, no context. For each answer record:
- **Correct?** (Yes / Partial / No)
- **Right document?** (Yes / No — did it cite the most authoritative source?)
- **Citation accurate?** (Yes / No — does that page actually say what the answer claims?)
- **Notes** — what was wrong, missing, or surprisingly good

Rate each: ✅ Good / ⚠️ Partial / ❌ Wrong / 🔲 No answer
